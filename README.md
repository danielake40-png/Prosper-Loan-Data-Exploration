#Prosper Loan Data Exploration

##Project Overview

This project explores 113,937 Prosper Loan records using Python to identify patterns in borrower characteristics, loan amounts, credit ratings, repayment terms, and borrowing costs.

#Project Objectives

* Examine loan and borrower characteristics.
* Investigate relationships between borrower income and loan amounts.
* Analyze credit ratings and borrowing costs.
* Explore repayment term patterns.
* Communicate findings through 10 visualizations.

#Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

#Key Findings

* Borrower income showed a moderate positive correlation with original loan amount (r ≈ 0.404 for the analyzed income range).
* Higher Prosper credit ratings were generally associated with lower APRs.
* The 36-month repayment term was the most common.
* Longer repayment terms were associated with larger loan amounts.
* Extreme income observations affected the distribution of stated monthly income.

#Project Deliverables

* Jupyter Notebook containing the Python analysis.
* HTML report containing the visualizations and findings.
* Project documentation.

#Conclusion

This exploratory analysis demonstrates practical skills in data assessment, visualization, statistical interpretation, and communicating financial insights. The findings describe associations rather than causal relationships.
